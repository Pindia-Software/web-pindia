## 🎨 PROMPT BASE (CONSTANTE)

Este prompt debe usarse como base para TODAS las imágenes. Simplemente añade la escena específica del artículo al final.

```
Ilustración vectorial plana 2D, estilo editorial moderno. Fondo azul marino profundo (#14213D). Personaje principal: robot mascota amistoso con cuerpo rojo coral (#E63946), cabeza cuadrada de esquinas redondeadas con una pequeña antena fina en lo alto, un único ojo redondo blanco con punto negro central, ranura horizontal blanca a modo de boca, tres rayas blancas paralelas en cada brazo justo encima del codo, rodillas con bandas blancas a modo de articulación, manos simples curvadas, zapatos blancos redondeados. Líneas limpias, geométricas, sin gradientes ni texturas, sin sombras realistas, paleta muy limitada (azul marino, rojo coral, blanco y un único color de acento por escena). Composición horizontal 16:9 centrada y equilibrada, con el robot y los elementos secundarios distribuidos por todo el encuadre. Sin texto, sin letras, sin números, sin tipografía de ningún tipo en la imagen. Pensada para usarse como cover de blog donde el título aparece por separado, fuera de la imagen, en la maquetación HTML. No fotorealista. Coherencia 1:1 con el robot de referencia adjunto.
```

## 📋 INSTRUCCIONES DE USO

### Paso 1: Preparación Inicial (Una sola vez)
1. Abre ChatGPT con tu plan Plus o superior
2. Crea un nuevo chat
3. Sube la imagen de referencia del robot (Robot2.svg) como archivo adjunto
   - Esto proporciona coherencia visual en todas las generaciones

### Paso 2: Para Cada Nueva Imagen
1. **Copia el PROMPT BASE** completo
2. **Añade la escena específica** (ver ejemplos arriba)
3. **Añade al final**: `Formato 16:9 horizontal, alta resolución.`
4. **Pega el prompt completo** en ChatGPT
5. **Espera la generación** (~30-60 segundos)
6. **Descarga la imagen** usando el botón de descarga

### Paso 3: Procesamiento Automático
Una vez descargada, ejecuta este comando Python para convertir a WebP y guardar en la carpeta correcta:

```python
from PIL import Image
import os
from pathlib import Path

# Configuración
src = "/Users/borjagarciacueto/Downloads/[NOMBRE_ARCHIVO_DESCARGADO].png"
dst = "/Users/borjagarciacueto/Documents/Claude/Projects/web-pindia/assets/img/blog/[SLUG]/cover.webp"

# Procesar
img = Image.open(src).convert("RGB")
w, h = img.size
nw = 1600
nh = int(h * (nw / w))
img = img.resize((nw, nh), Image.LANCZOS)

# Crear directorio y guardar
Path(dst).parent.mkdir(parents=True, exist_ok=True)
img.save(dst, "webp", quality=85, method=6)

print(f"✅ Guardado: {dst}")
```

## 🎯 Pautas de Diseño

### Colores de Acento
Cada imagen tiene un color de acento único (además del azul marino y rojo coral):
- **Amarillo mostaza**: Precios, cálculos, SEO local
- **Turquesa claro**: Diseño, creatividad
- **Verde menta**: E-commerce, tiendas
- **Naranja suave**: Presentación, ejemplos, conversión
- **Púrpura**: Decisiones, comparativas
- **Verde lima**: Velocidad, rendimiento
- **Rojo intenso**: Errores, problemas
- **Beige cálido**: PYME, negocios locales
- **Dorado**: Profesionalismo, gastronomía
- **Azul claro**: Accesibilidad, inclusión
- **Verde azulado**: Integración técnica

### Composición
- Formato **16:9 horizontal** (1600x900px recomendado)
- Composición **centrada y equilibrada**
- Robot **visible y protagonista**
- Elementos secundarios **distribuidos por todo el encuadre**
- **SIN TEXTO NI TIPOGRAFÍA** (el título va fuera en HTML)
- Líneas **limpias y geométricas**
- **Sin gradientes, texturas ni sombras realistas**
- Paleta **muy limitada** (máximo 4-5 colores)

### Elementos Secundarios
Los elementos secundarios deben ser geométricos y relacionados con el tema:
- Ventanas de navegador (flotantes, planas)
- Iconos geométricos simples
- Mapas estilizados
- Herramientas (llave inglesa, lupa, etc.)
- Símbolos (euro, código, etc.)
- Naturaleza estilizada (plantas, gaviotas)
