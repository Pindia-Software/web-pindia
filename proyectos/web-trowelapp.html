La web comercial de TrowelApp: de un idioma a nueve mercados en una semana

Pindia diseñó y desarrolló de cero la nueva web comercial de TrowelApp, el SaaS de gestión de obra. Una landing orientada a conversión, construida en HTML, CSS y JavaScript a medida e internacionalizada de un único idioma —castellano— a nueve locales para España, Latinoamérica y el mercado anglosajón. Entregada en una semana.

El reto

Vender un SaaS complejo en varios mercados

TrowelApp ya tenía web, pero solo en castellano y centrada en un único mercado. El objetivo: una web comercial nueva, más clara y orientada a conversión, capaz de explicar un producto con muchos módulos y, a la vez, hablar a la vez a España, Latinoamérica y al mercado anglosajón. Con un plazo de una semana.

  • Comunicar un SaaS con muchos módulos —presupuestos, costes, calidad, tiempos— de forma simple y accionable.
  • Internacionalizar la web: pasar de un solo idioma a 9 locales con hreflang correcto por mercado.
  • Maximizar la conversión a «Agendar demo» en cada sección, sin saturar.
  • Rendimiento y SEO técnico multipaís, con imágenes WebP y carga diferida.
  • Entregar en una semana, diseño y desarrollo incluidos.

La solución

El producto, explicado en tres golpes de vista

La home presenta el producto con mockups reales del SaaS y un selector de funcionalidades clave —presupuestos, control de costes y cashflow— para que cualquier visitante entienda el valor en segundos antes de pedir una demo.

Para quién

Una web que habla a cada oficio

La web segmenta el mensaje por perfil de empresa. Cada vertical tiene su propia narrativa e imágenes reales de obra, para que el visitante se reconozca de inmediato.

App móvil

La obra, también en el bolsillo

La web destaca la app móvil como pieza central del producto: trabajo a pie de obra, modo offline, geolocalización opcional y captura de fotos y firmas. El bloque combina mockup real y enlaces a las stores.

  • Mockup real de la app integrado en la narrativa de la home.
  • Mensaje «oficina + obra»: web para la oficina, app para el tajo.
  • Llamadas claras a descargar e iniciar la demo.
Stack tecnológico

Sin frameworks, a medida y rápida

La misma filosofía que aplicamos a nuestra propia web: HTML, CSS y JavaScript a medida, sin CMS ni dependencias pesadas. Resultado: control total del marcado, rendimiento alto y una base i18n limpia para escalar a nuevos mercados.

Estructura

HTML5 semántico

Marcado limpio y accesible, jerarquía de encabezados correcta y metadatos por idioma. Base sólida para SEO multipaís.
