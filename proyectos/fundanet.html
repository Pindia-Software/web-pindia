Fundanet: dos webs para una empresa que gestiona la investigación

Fundanet desarrolla software para gestionar la investigación: ensayos clínicos, gestión de proyectos, justificación económica y transferencia de resultados. Además tiene una academia que forma a sus usuarios y los certifica. Hicimos el diseño y el desarrollo WordPress de las dos webs, cada una con su propio público.

El reto

Dos públicos, una misma marca

Fundanet vende software a responsables de investigación, centros de investigación clínica y oficinas de proyectos. Y a los usuarios de ese software les ofrece formación y certificación oficial. Son personas distintas, con preguntas distintas, y una sola web no podía contestar a las dos bien.

Cuatro objetivos guiaron el proyecto:

  • Cada web habla a su público desde la primera pantalla: quien busca software no tiene que atravesar la formación, y quien busca formación encuentra el acceso a la plataforma sin más pasos.
  • Tres idiomas en la web de software: español, inglés y portugués de Portugal, cada uno con su propia versión de cada página.
  • Un camino claro a la certificación: cursos, webinars, formación a medida y certificado de usuario, en una sola navegación.
  • Un equipo que pueda seguir editando: WordPress con Elementor, para que los textos y las páginas se cambien desde el propio panel.
Solución · Decisiones de diseño y UX

Tres decisiones que definen las dos webs

Dos webs, no una

Software y formación tienen dominios, menús y mensajes propios. Así, cada visitante ve lo que le importa y ninguno tiene que buscar la otra mitad de la empresa.

Tres idiomas con etiquetas correctas

La web de software está en español, inglés y portugués de Portugal, con las versiones enlazadas entre sí (hreflang) para que Google muestre a cada persona la suya.

Academia con acceso directo

El acceso a la plataforma de formación está en la cabecera de la academia, y la oferta se organiza en cursos oficiales, webinars y formación a medida para empresas.

Recorrido del sitio

Cómo se lee cada web

Cada web abre con la pregunta de su público. En la de software, la presencia internacional y las localizaciones. En la academia, el acceso a la formación.

Stack tecnológico

WordPress con Elementor, editable por el equipo

Las dos webs están montadas sobre WordPress con Elementor Pro y el tema Astra. Es una base que el equipo de Fundanet puede editar, y que se puede ampliar sin rehacer las páginas.
